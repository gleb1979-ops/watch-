# Траппкинс: Побег из аквапарка

Браузерная игра: Джейден, Лео, Мия и Бисквит убегают от грабителей в аквапарке.

Три иллюстрированные локации, анимация ходьбы, пять ловушек, преследование на лестницах и горках, спуск от третьего лица с управлением и полноэкранный интерфейс.

## Запуск

Откройте `index.html` в Chrome или Edge и нажмите «Играть на весь экран». Для разработки можно запустить `python3 -m http.server 8000` из корня проекта. Внешних зависимостей и API нет.

WASD / стрелки — движение, 1–3 — выбор героя, E — выбранная ловушка, пробел — способность, Escape — пауза. Все основные действия доступны кнопками в игровом интерфейсе.

## GitHub Pages

Для публикации через GitHub: Settings → Pages → Deploy from a branch → `gh-pages`, `/ (root)` → Save. Адрес сайта после успешной публикации: `https://gleb1979-ops.github.io/watch-/`.

## Ресурсы

Исходные персонажи и анимации взяты из предоставленной пользователем первой части. Иллюстрации локаций, спуска и сидящих персонажей созданы генерацией изображений.
